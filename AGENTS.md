# Repository instructions

- Treat this as a clean-room OSS incubation repository.
- Read SCOPE.md and PROVENANCE.md before changing files.
- Do not import code, fixtures, prompts, traces, schemas, or requirements from any private or partner repository.
- Use public primary sources and synthetic fixtures; log them in PROVENANCE.md.
- Keep the v0 narrow. Do not add a dependency when the standard library is sufficient.
- Non-trivial logic requires one small runnable test.
- Do not change repository visibility or add a public license without explicit owner approval.

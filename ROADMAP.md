# Roadmap

This roadmap communicates direction, not a delivery promise.

## 0.1 — Runnable local proof

- Deterministic JSON and accessible static HTML.
- Explainable license, provenance, remote, registry, URL, submodule, binary, and LFS boundary checks.
- Synthetic green, amber, and red examples.

## Candidate 0.2 work

- Configurable, versioned allowlists with findings that show which exception applied.
- More precise SPDX-expression handling without claiming legal clearance.
- SARIF export if it can preserve the same evidence model.
- Repository-size safeguards and clearer skipped-file accounting.

## Before 1.0

- Stabilize the JSON schema and rule identifiers from public feedback.
- Publish an explicit deprecation policy and migration tooling.
- Complete independent security, accessibility, ownership, and trademark review.

Hosted scanning, secret discovery, and automated legal decisions remain out of scope.

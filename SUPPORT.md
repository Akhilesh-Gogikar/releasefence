# Support

ReleaseFence is an early OSS project maintained on a best-effort basis.

- Usage question or false positive: open a GitHub issue using the bug template and provide a minimal synthetic tree.
- New check or report improvement: use the feature template.
- Vulnerability or sensitive repository detail: use the private route in [SECURITY.md](SECURITY.md), never a public issue.

Before asking, run `releasefence --help`, review [troubleshooting](docs/TROUBLESHOOTING.md), and confirm the behavior on the included synthetic examples. There is no guaranteed response time, legal review, or private repository support channel.

# Security policy

## Supported versions

Until 1.0, only the latest tagged 0.x release and `main` receive security fixes.

## Report privately

Do not open a public issue for a vulnerability, credential exposure, unsafe path handling, or a report that reveals private repository facts. Open a private GitHub security advisory:

<https://github.com/akigogikar/releasefence/security/advisories/new>

Describe the affected version, operating system, minimal synthetic reproduction, impact, and any proposed mitigation. Do not attach private source or real credentials. Expect acknowledgement within seven days; remediation timing depends on severity and reproducibility.

ReleaseFence reads local trees. Run it only on repositories you are authorized to inspect, review report files before sharing, and keep generated reports out of public artifacts when their evidence is sensitive.
